# Car Scanner Graf

Однофайловый HTML-анализатор логов [CarScanner Pro](https://www.car-scanner.info/) для диагностики турбомоторов. Открывается прямо в браузере, ничего не устанавливает, работает офлайн.

![license](https://img.shields.io/badge/license-MIT-green.svg)

## Возможности

- 📈 Графики всех параметров лога на общей временной шкале
- 🔍 Зум и прокрутка по времени (`Shift` + колесо мыши, ползунки)
- 🖱 Перетаскивание графиков для изменения порядка (порядок сохраняется)
- 🧩 Неизвестные параметры из файла рисуются автоматически
- 💾 Настройки (порядок, окно, масштаб) сохраняются в cookies
- ⚠️ **Анализатор опасных событий** (см. ниже)

## Использование

1. Сохраните `index.html` и откройте в браузере (Chrome / Edge / Firefox).
2. Загрузите CSV-лог кнопкой **«+»** или перетащите файл в окно.
3. Наведите курсор на график — увидите точное значение. `Shift` + колесо — прокрутка по времени.
4. Панель «Анализатор опасных событий» свёрнута под шапкой — кликните, чтобы развернуть. Клик по событию переносит к нужному моменту и подсвечивает график.

## Формат лога

Экспорт из CarScanner Pro: **Логгер → записать → Экспорт / Поделиться → CSV, вертикальный формат**. Каждая строка — четвёрка полей через `;`: "33176.9982153";"Массовый расход воздуха";"6.66";"g/sec";


`время ; имя параметра ; значение ; единица измерения`

## Анализатор опасных событий

### Откат УОЗ (красный маркер)
Детонация возникает под нагрузкой, и ЭБУ гасит её откатом угла (до ~10–14°). Опасным считается откат, если **все** условия выполнены:

- УОЗ < 0
- обороты > 1000 (холостой ход игнорируется — там минусовой УОЗ норма)
- **ДПДЗ ≥ 15%** (педаль нажата; < 15% = педаль отпущена, штатный режим торможения/отсечки)
- обороты после точки **не падают** (падение = переключение или сброс газа)
- если в логе есть «Расчетное значение нагрузки на двигатель» — нагрузка ≥ 25%

ДПДЗ ≥ 84% помечается как «тапка в пол» (WOT) — самые опасные откаты.

### Хлопание дросселя (оранжевый маркер)
Зигзаг ДПДЗ в зоне ~45–85% с плечами от 8% при оборотах > 1000 без их падения — возможный признак неисправного ДПДЗ / дросселя.

### Аномалии турбины (голубой маркер, по «Расчетному наддуву»)
- **Недодув**: ДПДЗ ≥ 84% (тапка в пол), обороты > 2000, а наддув < 0.3 bar — турбина не выходит на режим.
- **Резкий сброс наддува**: падение > 0.5 bar за замер при нажатом газе (ДПДЗ > 50%) — утечка / вестгейт.
- **Скачок наддува**: рост > 0.5 bar за замер — риск передува.

Все пороги вынесены в константы в начале скрипта (`MIN_RPM`, `TPS_RELEASED`, `TPS_WOT`, `LOAD_MIN`, `TURBO_*` и т.д.) — подкручивайте под свой мотор.

## Как уменьшить интервал опроса (Δt)

- Включите оптимизацию (пакетный) опроса в настройках CarScanner.
- Используйте быстрый адаптер — например **vLinker** (дешёвые ELM327 заметно медленнее).
- Уменьшите число параметров на панели приборов CarScanner.
- Отключите постоянное считывание расхода топлива.
