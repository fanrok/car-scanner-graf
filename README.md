# Car Scanner Graf

Однофайловый HTML-анализатор логов [CarScanner Pro](https://www.car-scanner.info/) для диагностики турбомоторов. Открывается прямо в браузере, ничего не устанавливает, работает офлайн.

![license](https://img.shields.io/badge/license-MIT-green.svg)

## Возможности

- 📈 Графики всех параметров лога на общей временной шкале
- 🔍 Зум и прокрутка по времени (`Shift` + колесо мыши, ползунки)
- 🖱 Перетаскивание графиков для изменения порядка (порядок сохраняется)
- 🧩 Неизвестные параметры из файла рисуются автоматически
- 💾 Настройки (порядок, окно, масштаб) сохраняются в cookies
- ⚠️ **Анализатор опасных событий** (см. ниже)

## Использование

1. Сохраните `index.html` и откройте в браузере (Chrome / Edge / Firefox).
2. Загрузите CSV-лог кнопкой **«+»** или перетащите файл в окно.
3. Наведите курсор на график — увидите точное значение. `Shift` + колесо — прокрутка по времени.
4. Панель «Анализатор опасных событий» свёрнута под шапкой — кликните, чтобы развернуть. Клик по событию переносит к нужному моменту и подсвечивает график.
