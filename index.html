Управление (компьютер)

Shift + Колесо мыши — прокрутка позиции.
Ползунки «Окно» и «Позиция», 🔍+ / 🔍− — масштаб.
Наведите курсор на график — точное значение.
Зажмите ЛКМ на графике и тяните — перестановка (запоминается).
Кнопка «Сброс» — зум и порядок графиков по умолчанию (по списку ROLES).

Управление (телефон)

Тап по графику — вертикальная линия и значение.
Свайп влево/вправо по графику — прокрутка времени.
Щипок двумя пальцами — изменение «Окна».
Полоса внизу — таймлайн.

Порядок графиков

По умолчанию графики идут в порядке списка ROLES (обороты, УОЗ, детонация, коррекция и т.д.), затем все остальные параметры. Если вы переставили графики перетаскиванием, порядок сохраняется — «Сброс» вернёт стандартный.

Анализатор опасных событий

  • Откат УОЗ (красный): минусовой УОЗ при оборотах > 1000, нажатой педали (ДПДЗ ≥ 15%) и неповороте оборотов. Поддерживается УОЗ по цилиндрам. Если рядом детонация — жёлтое кольцо + «⚡детонация».
  • Детонация (пульсирующий красный): сигнал «Knock detected» = 1 из ЭБУ.
  • Хлопание дросселя (оранжевый): скачки ДПДЗ ~50–80% при оборотах > 1000.
  • Аномалии турбины (голубой): недодув при тапке в пол, резкий сброс / скачок наддува.
  • Панель событий свёрнута — кликните, чтобы развернуть. Клик по событию — переход.

Распознавание параметров

Параметры определяются по ключевым словам, независимо от регистра и префиксов [ДВС]/[ECM]. Отбрасывается только дубль «Обороты двигателя x1000». Неизвестные параметры рисуются внизу.

Экспорт из CarScanner Pro

Логгер → записать → Экспорт / Поделиться → CSV, вертикальный формат.

"33176.9982153";"Массовый расход воздуха";"6.66";"g/sec";

Как уменьшить Δt

  • Оптимизация опроса в настройках CarScanner (пакетный режим).
  • Быстрый адаптер — vLinker (дешёвые ELM327 медленнее).
  • Меньше параметров на панели приборов.
  • Отключить постоянное считывание расхода топлива.
